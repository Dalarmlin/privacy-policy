隱私權政策

最近更新日期：2026 年 10 月 13 日

歡迎使用本應用程式（以下簡稱「本服務」）。本服務極為重視您的個人資料與隱私權保護。為落實台灣《個人資料保護法》及相關法令規範，我們制定了本《隱私權政策》（以下簡稱「本政策」），向您說明我們如何收集、處理、利用及保護您的個人資料。請在使用本服務前，仔細閱讀並瞭解本政策之內容。當您開始使用本服務，即表示您已閱讀、瞭解並同意接受本政策之所有內容。

一、個人資料收集與處理之原則

我們遵循台灣《個人資料保護法》之規定，恪守以下原則保護您的個人資料：

  • 權責一致與透明原則：明確告知收集目的、利用方式，以及使用者輸入第三人資料時之權責歸屬。
  • 最小化與必要性原則：僅處理提供服務所必需之最少資料。第三人資料中，傳送至 AI 分析的僅有由其出生年份推算之四化結果，不傳送姓名、出生日期或備註等直接識別資訊。
  • 目的明確與限制利用原則：僅於提供命盤解析、AI 諮詢等收集目的之必要範圍內處理與利用。
  • 使用者授權擔保原則：若您於本服務中輸入或查詢任何第三人（如親友、同事、合作夥伴）之生辰或個人資訊，您必須確保已取得該第三人之明確同意或合法授權。因未獲授權輸入他人資料而衍生之任何法律責任，應由輸入資料之使用者自行承擔。
  • 安全性原則：採用合理之技術與管理措施保護資料安全，並將資料儲存於使用者個人裝置本機端。

二、個人資料之收集、利用與儲存方式

（一）不主動收集個人身分資料

本服務不提供帳號註冊與登入功能，亦不會要求您輸入身分證字號、聯絡電話或電子郵件等可直接識別身分之個人資料。

（二）本地端資料儲存

您於本服務內輸入之本命資料（出生日期、時間、性別、出生地）、關係人清單（您自訂的稱呼、出生年份、選填的出生日期與備註）、AI 解算紀錄及個人設定，皆儲存於您個人行動裝置之內部儲存空間，我們不會上傳至自有伺服器保存。若您於裝置上開啟 iCloud 或 Google 備份，上述資料可能包含在作業系統之裝置備份中，由 Apple 或 Google 依其政策處理。

（三）人工智慧（AI）分析與第三方 API 服務（Google Gemini API）

為了提供命盤解析、隨身提問等 AI 功能，本服務整合了 Google Gemini API：

  • 傳輸範疇：當您使用 AI 功能時，僅傳送該次分析所需之結構化命盤資料（宮位、星曜、流年／流月／流日運限，以及關係人由出生年份推算之四化），以及您於隨身提問輸入之問題內容。關係人姓名不會傳送，一律以代號（如 T1、T2）表示；但您自行輸入於問題中的文字會原樣傳送。資料以加密傳輸（HTTPS/TLS）方式經本服務之轉送伺服器傳送至 Google Gemini API 進行即時運算。
  • 資料處理與隱私：上述資料僅用於生成當次分析結果，本服務於回應完成後不保留請求內容，亦不會將可識別您身分之資料連結至該請求。建議您向 AI 提問時，避免輸入姓名、身分證字號、銀行帳號等敏感資訊。
  • 第三方服務條款：Google 對傳輸資料之處理，依 Google 隱私權政策與 Google API 服務條款辦理。

（四）不使用統計分析工具

本服務未使用任何第三方統計分析或使用者行為追蹤工具。

（五）廣告服務

免費版可能透過第三方廣告服務（如 Google AdMob）顯示廣告。廣告服務商可能收集裝置之廣告識別碼、概略裝置資訊與廣告互動資料，用於投放與成效衡量，其處理方式依各廣告服務商之隱私權政策辦理。升級 Pro 方案後將不再顯示廣告。

（六）付款與訂閱

Pro 方案之付款由 Apple App Store 或 Google Play 處理，本服務不會取得您的信用卡或付款資訊，僅會收到用於確認方案狀態之購買憑證。

三、Cookie 及類似技術之使用

本服務為行動應用程式，不使用 Cookie，亦不進行跨應用程式追蹤。

廣告服務可能使用裝置之廣告識別碼（Android 廣告 ID 或 iOS IDFA）。您可隨時於裝置之系統設定中重設廣告識別碼、限制個人化廣告或拒絕追蹤。

四、系統權限申請與使用說明

本服務僅會在您使用特定功能時，經您同意後向系統申請以下權限：

  • 定位權限（僅限使用期間）：用途：於輸入出生地時點選「當前位置」，讀取一次概略經緯度以帶入出生地經度，提升排盤精準度。位置資訊僅於裝置上使用，不會傳送至任何伺服器。使用時跳出提示申請權限。
  • 生物辨識權限（Face ID／指紋）：用途：開啟 App 鎖定功能時，用於解鎖本服務。辨識過程由作業系統處理，本服務不會取得您的生物特徵資料。使用時跳出提示申請權限。

五、個人資料之保護與安全措施

  • 安全防護：我們採用符合業界標準之安全防護技術（例如 SSL/TLS 加密傳輸技術及 HTTPS 安全連線），防止資料在傳輸至 API 或伺服器過程中遭未授權存取、洩漏、篡改或毀損。
  • 網際網路風險提示：請注意，網際網路傳輸並非絕對安全之環境。建議您切勿透過非加密之通訊管道傳送敏感個人資料。

六、個人資料之揭露與第三方提供

除本政策已載明之第三方服務（Google Gemini API、廣告服務、Apple App Store／Google Play）外，除非符合以下情形之一，我們絕不會將您的個人資料出售、出租、交換或揭露予任何第三方：

  • 基於法律規定：應司法機關、警察機關或主管機關依法定程序之要求。
  • 保護生命安全：為免除您或他人生命、身體、自由或財產上之急迫危險。

七、您的權利（個資法當事人權利）

依據台灣《個人資料保護法》第 3 條規定，您就我們所持有之您的個人資料，享有以下權利：

  1. 查詢或請求閱覽。
  2. 請求製給複製本。
  3. 請求補充或更正。
  4. 請求停止收集、處理或利用。
  5. 請求刪除。

註：由於本服務之命盤與關係人資料完全儲存於您的個人裝置內，您可隨時於 App 內編輯或刪除，或透過清除應用程式資料、解除安裝本服務來刪除該等資料。

八、隱私權政策之變更與修訂

我們可能因應法律變更、營運需求、AI 技術更新或服務調整，不定時修訂本政策。修訂後的條款將公佈於官方網站或應用程式內，並更新生效日期。若您於政策更新後繼續使用本服務，即視為您已同意並接受修訂後的隱私權政策。
